# 🌐 Internet Border Patrol

## 📌 Project Description
This project is used to check whether a website is safe or malicious using API analysis.

## 🚀 Features
- Check URL safety
- Detect malicious websites
- Display analysis results
- Simple and easy interface

## 🛠️ Technologies Used
- Python
- Requests Library
- VirusTotal API

## ▶️ How to Run
1. Install Python
2. Install required packages:
   pip install requests
3. Run the file:
   python main.py

## 📷 Output
Shows whether the website is safe or not based on analysis.
